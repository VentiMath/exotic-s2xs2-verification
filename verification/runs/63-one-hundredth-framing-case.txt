This was the sole case left inconclusive after Run 62.  As throughout the

Common-core reduction
---------------------

The frozen four-generator presentations for this case and for the already
certified neighboring case

  n1_y2_ap1_bp1_jap1_jbp1

each contain 97 relators.  Direct comparison shows that relators 2--97 are
identical, while only relator 1 differs.  Write the shared 96-relator quotient
as C and the two first relators as r0 and r1.

A shortlex completion of C with

  maxeqns  = 300000
  tidyint  = 500
  maxstates = 2000000

is confluent.  Its checked target reductions are

  g1 = 1,  g3 = 1,  g4 = 1,
  r0 = g2^-1,  r1 = g2^-1.

Thus C is generated by g2, and its abelianization is Z.  More importantly for
case 100, its exact presentation is C with r0 imposed.  Since r0 = g2^-1 in C,
that relation kills g2.  All four generators are therefore trivial.  The r1
reduction is a cross-check only; the prior n1 certificate is not an input to
this proof.

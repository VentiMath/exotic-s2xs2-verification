Run 61: two more framing holdouts certified at the raised equation limit
============================================================================

Cases
-----

  n0_y1_am1_bm1_jam1_jbm1   signs (-1,-1), shift (-1,-1)
  n0_y1_ap1_bm1_jap1_jbm1   signs (+1,-1), shift (+1,-1)

Both cases were among Run 59's five default-limit holdouts. A parallel
Claude/Fable sweep first obtained console-level confluent completions from
their unchanged fill-then-base raw presentations after raising KBMAG's
equation ceiling from 32,767 to 300,000.

This run independently converted both observations into proof certificates.
For each case, the exact Run 59 97-relator input was serialized with

  maxeqns = 300000
  tidyint = 100

The proof-producing KBMAG executable then recorded every derived equation and
its parents. No relator, generator, or alphabet-order change was made.

  n0_y1_ap1_bm1_jap1_jbm1   1,636 proof records, 0 fallback searches

For each certificate:

  Python verifier: VERIFIED TRIVIAL
  Ruby verifier:   ALL RUBY FILLED-GROUP CHECKS PASSED

Both independent verifiers begin with the certificate's SHA-256-bound
97-relator presentation, replay every free-group derivation, and check that
all four original generators have identity roots. The console completion is
therefore no longer a trust boundary.

Run 34: independent marked-fiber realization (2026-08-25)
============================================================

Purpose
-------

Remove the last shared construction input of the two bundle routes: both had
started from `fiber.build_fiber`. This run constructs the marked genus-2
surface a second way and compares the complete equivariant filling ribbon
graph, not merely homology or the curve intersection matrix.

Independent construction
------------------------

`luttinger/independent_fiber.py` does not import `fiber.py`. It starts from an
abstract ordered five-chain graph with four crossings and eight unsplit curve
segments. To avoid copying the primary plumbing, it:

* subdivides the two loop edges and specifies a six-vertex ribbon rotation;
* builds six explicit triangulated vertex disks;
* attaches ten independently triangulated rectangular edge bands;
* finds the two boundary cycles combinatorially and cones them from p and O;
* records literal chordless core cycles a,b,c,d,e; and
* defines an explicit simplicial chain-reversing involution.

The resulting surface is different from the primary one:

  independent f-vector   [58,180,120]
  primary f-vector       [86,264,176]

Both have Euler characteristic -2. Every edge has degree two, every vertex
link is one circle, and the surfaces are orientable. The independent curves
have lengths 5,6,6,6,5, meet exactly in the ordered five-chain pattern, and
their complement has exactly two Euler-characteristic-one faces containing p
and O. Each explicit cap is separately checked as a combinatorial disk.

Equivariant marked comparison
-----------------------------

`luttinger/independent_fiber_audit.py` extracts from each triangulation:

* the cyclic order of all four directed curve ends at every crossing;
* the pairing of directed ends into curve segments;
* the two ribbon boundary cycles, labeled by their p and O complementary
  components; and
* the involution image of every directed curve end.

It searches all 32 irrelevant choices of curve orientations and both global
surface orientations, producing a canonical marked ribbon code. The two codes
are identical, with SHA-256 digest

  3b07cadf43e3ff010a0c7159a3e138cadc880856df153762fd347022be2d66aa

This certifies the full equivariant ribbon equivalence: the curve names,
crossing rotations, p/O faces, chain-reversing involution, and free action on
c all agree. An identity-involution mutation is distinguished and a p/O-swap
mutation is rejected.

Common subdivision
------------------

The code records an explicit common subdivision count for every compressed
curve segment:

  a,e:       5 versus 8 edges  -> 40 common edges
  b,c,d:     3 versus 4 edges  -> 12 common edges on each segment

The ribbon equivalence thickens over these common subdivisions and extends
over the two labeled disks by coning. Thus the comparison is not based on
matching f-vectors or an abstract genus calculation.

Run 32: exact based monodromy in the alternative beta trace (2026-08-25)
===========================================================================

Purpose
-------

Upgrade Run 31's homology-only comparison to the full based fundamental
group. This directly tests whether the independent 64-interface construction
could agree after abelianization while representing a different mapping
class, or could transport the correct unbased curves with incorrect whiskers.

Independence boundary
---------------------

`luttinger/alternative_based_monodromy.py` imports none of `bundle.py`,
`layers.py`, or `paper_bridge.py`. It uses:

* the alternative open beta trace from Run 31;
* the separately reconstructed literal p-whiskered rail loops x,y,r,s;
* a rank-sorted 2-skeleton presentation routine; and
* the generic proof-producing Tietze eliminator and its replay checker.

The marked fiber remains shared, exactly as recorded in Run 31.

Exact based residuals
---------------------

For each named bottom loop, the program forms the closed path

  bottom * vertical(p) * top_target^-1 * vertical(p)^-1.

Here `vertical(p)` is the literal 64-edge track of the basepoint through the
open stack, and the targets are

  x -> y^-1,  y -> yx,  r -> r,  s -> s.

Thus the calculation is based from its first edge and does not infer anything
from free homotopy or homology.

Conclusion
----------

The alternative beta trace has the exact based action

  x -> y^-1,  y -> yx,  r -> r,  s -> s.

This removes the homology-only limitation of Run 31. It is a second complete
based-pi1 calculation on a different triangulation, not a comparison of
mapping-torus fingerprints.
